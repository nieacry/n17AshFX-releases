# AshFX builds

Windows builds of **AshFX**, a parametric generator of hand-drawn 2D effects
(explosions, smoke, sparks).

## Install

1. Open [Releases](https://github.com/nieacry/n17AshFX-releases/releases) and download
   `AshFX-<version>-win64.zip` from the latest release.
2. Unzip it somewhere you can write to (Desktop, Documents, a project drive), not Program Files.
3. Run `AshFX.exe`. Keep the whole folder together.

Windows may warn about an unknown publisher on the first run (the build is not code-signed
yet): choose **More info → Run anyway**.

## Update

When a new version is out, AshFX shows an **Update to …** button in the top right corner.
Click it: the app downloads the new version, installs it next to the current one and restarts.
The previous version is kept, so nothing is lost if something goes wrong.

You can also use **Help → Check for Updates**.

## Feedback

Send feedback and bug reports to the person who gave you the build, with the version number
from the top right corner of the app.

This repository holds builds only. The source code is private.
